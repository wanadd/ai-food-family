# Roadmap

1. Accept target architecture and Core contracts: this checkpoint.
2. Design target physical V2 schema and module ownership boundaries.
3. Define versioned contracts, compatibility adapters, projections, and reconciliation evidence.
4. Implement only after design acceptance, with high-confidence migration and a single writer.
5. Validate controlled cutover, rollback, observability, and safety invariants.
6. Deprecate old readers after parity and cutover acceptance.

P1 portability work includes retailer and money. P2 work includes shared conversation and a physical Core service. These priorities do not change the current implementation block.
