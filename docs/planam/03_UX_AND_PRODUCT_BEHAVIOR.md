# 03 UX And Product Behavior

## Core journey

On first use, the user establishes the household context, receives an initial menu, and can act on it immediately. Returning users land on the current decision: cook, buy, use leftovers, or inspect a health-relevant issue.

## Interaction rules

- The primary CTA is often `Приготовить`, because completing the meal is the product outcome.
- Ask PLANAM opens as a sheet for clarification, substitution, and explanation; it is not the default home experience.
- Health is available in the free product as a useful baseline; PRO deepens health analysis rather than becoming a separate app.
- Allergies and hard exclusions are visible before a meal is accepted.
- Ambiguous data is explained as uncertainty, not hidden behind a confident label.
- Personal mode must work without mocked family defaults. Family mode is optional.

## Visual behavior

The UI is a calm Telegram Mini App: compact but breathable, touch targets at least 44px, clear hierarchy, light cards and thin borders, minimal shadows, and responsive light/dark behavior. It is not a CRM, spreadsheet, or calculator.
